Integrasi Bot Telegram (Notifikasi Dapur / Grup / Channel)

Panduan Aktivasi Tombol "Konfirmasi Selesai" di Grup / Channel:

  • Tambahkan bot Anda ke Grup atau Channel sebagai Administrator (agar bot bisa mengirim dan mengedit pesan saat tombol diklik).
  • Mode Real-Time (Webhook HTTPS / Cloudflare Tunnel): Masukkan URL publik menuju telegram_webhook.php di bawah lalu klik Set Webhook. Saat staf menekan tombol di Telegram, database langsung ter-update seketika.
  • Mode Lokal (Tanpa HTTPS Publik): Biarkan webhook kosong, dan gunakan tombol Sync Status Telegram di tab Riwayat Pesanan untuk menarik status klik tombol dari Telegram.
